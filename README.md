# PROGNODE — Professional V3 Website

V3 is the first serious pre-publication candidate.

## Improvements over V2.1
- More integrated PROGNODE brand treatment
- Interactive hero product demo
- Dashboard tabs: Overview / Alarms / Historian / Devices
- Integrated mobile alarm preview
- Stronger local-first and device-agnostic messaging
- More professional product screen section
- Improved hover, animation and pricing behavior
- Better mobile responsive behavior
- Separate English and Turkish pages for SEO

## Structure
- `index.html` — English
- `tr/index.html` — Turkish
- `assets/styles.css`
- `assets/app.js`
- shared product/brand visuals
- `.nojekyll`

## Publishing
Do not publish until final visual/content review.

When approved:
1. Create a public GitHub repository, e.g. `prognode-site`
2. Upload the CONTENTS of this folder to repository root
3. Settings → Pages
4. Deploy from a branch
5. Branch: `main`
6. Folder: `/ (root)`
